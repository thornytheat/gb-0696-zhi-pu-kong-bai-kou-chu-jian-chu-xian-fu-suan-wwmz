# 质谱字段与规则

sample_id保留前导零。kind取standard、blank、sample、control。area与internal_area为峰面积。level为标样浓度，单位支持ug/L、mg/L、ng/L；统一为ug/L。dilution必须大于0。

每批每检测项至少3个独立浓度点。最小二乘使用Decimal，分母为零拒绝；斜率非正拒绝。空白取同批同项的浓度中位数。净浓度允许为负；不能提前截零。稀释后检出限=0.05×倍数。控制样相对误差超过20%阻断。超过标曲响应范围优先于其他质控判断。

重复编号相同内容标DUPLICATE，不同内容标KEY_CONFLICT。采信包括标曲和空白，最终样品数不等于输入采信数。行数对账独立于样品结果数。

同一批次同一分析项内sample_id唯一；相同样品编号可在不同分析项或批次中复用。加标行(kind=spike)与母样共享编号，去重键并入类型；同一样品至多一条加标行，重复或冲突照常隔离。

## 加标回收与签发依据

kind=spike为基体加标行：sample_id取母样编号，level为加标量(按unit归一)，响应参与空白扣除与浓度复算，但不作为报告结果。回收率=(加标行浓度−母样外标浓度)÷(加标量×稀释倍数)。加标行无母样标SPIKE_ORPHAN；加标量非正或响应超曲线标SPIKE_INVALID；回收率超出0.5–1.5标SPIKE_RECOVERY，均隔离且不作为依据。

每份样品按依据签发：自身加标(OWN_SPIKE，回收率可用)→可签发；同批均值(BATCH_AVG，同批同项有效自身加标的均值，标注n)→可签发·借据；外标未修正(EXTERNAL，无任何加标证据)→暂缓签发。默认取最优可用依据；修正浓度=外标浓度÷回收率，保留4位小数。检出状态按签发浓度复算，超限行保持阻断。借据样品必须与自身加标样品可区分。

浓度、检出状态与证据导出自同一份resolved记录；POST /api/basis切换依据先校验后落库，失败保留原报告；同一文件重跑复用原批次，不新增结论、不覆盖已切换依据；原始进样行随导出保留。
